# President's Cup Write-Ups

As I go through the practice area for CISA's President's Cup CTF, I like to create write-ups for each of the challenges I complete and share them here. Keeping track of the steps I take to solve each challenge helps me digest what I've learned, and it's nice to be able to look back at what I've done holistically to get a better understanding of the purpose of each challenge.

Shoutout to the CISA President's Cup team for always putting on a fun event and maintaining this practice range!
